# Cheese.Graduation — Premium Editorial UI 2026

Bản này là một hướng giao diện mới theo phong cách **premium / editorial / luxury studio**, giữ nguyên logic website hiện tại.

## Điểm đã nâng cấp

- Trang chủ: hero ảnh chuyển động tối hơn, layout chữ lệch trái kiểu editorial, thanh điều hướng floating glass, bảng màu navy sâu + ivory + champagne gold.
- Photographer: card nhẹ, ít viền, khoảng thở lớn, CTA bo pill và cảm giác cao cấp hơn.
- Real Work: chuyển sang gallery nền navy, tăng độ tập trung vào ảnh.
- Process / Trust / CTA cuối trang: đồng bộ typography, card, shadow và watermark cheese.graduation.
- Đăng nhập chung: thiết kế split-screen studio access, ảnh lớn bên trái và form sạch bên phải.
- Lịch thợ / Admin: giữ toàn bộ chức năng, làm lại lớp card, panel, thanh điều hướng và form theo hệ UI mới.
- Bảng giá / Thư viện / Đặt lịch: đồng bộ với cùng ngôn ngữ thiết kế.
- Responsive mobile được bổ sung ở lớp override mới.
